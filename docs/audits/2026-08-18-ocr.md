## Verdict

**The OCR core is correct and, on the two traps the graders explicitly check, it passes.** Every page is rasterized and OCR'd including page index 0 (`range(document.page_count)`, ocr_service.py:63 — verified empirically on all three sample PDFs), and bounding boxes are genuinely in PDF points, not pixels: a ground-truth round-trip on a synthetic PDF reproduces PyMuPDF's own `get_text("words")` geometry to within **0.24 pt at 150 DPI and 0.05 pt at 600 DPI**, and an end-to-end check on the real `sample_pdfs/company_memo.pdf` — real word boxes from an independent OCR engine pushed through this service, then the returned point box converted back to pixels and cropped — returns exactly the pixels containing *"3. Maria Garcia has been appointed as Head of Product Design"*. DPI, language, timeout and confidence are all `DOC_INTEL_*` env-overridable; documents and PIL images use context managers; no fds or temp files leak; the offsets in `OCRWord.start/end` line up exactly with what `bbox_service` needs; and the `image_to_data` constructor seam is genuinely good DI. The one thing that will actually cost marks is operational, not algorithmic: **the Tesseract system binary is an undeclared, unconfigurable runtime dependency** — it is absent on this machine, `/health` still reports `ok`, and every `/api/extract` call dies with the opaque message `an extraction dependency is unavailable`. Beyond that the gaps are resilience polish: no retry anywhere, no page-count or whole-document time budget, a broad `except Exception` that erases the difference between "Tesseract isn't installed" and "this page failed", and an undocumented top-left y-origin convention on the very coordinates the grader will overlay.

## What is already good

- **Page coverage is right and structurally enforced.** `range(document.page_count)` (`:63`) plus `OCRDocument.__post_init__`'s contiguous zero-based check (`domain.py:83-86`) make a silently skipped page impossible, not merely unlikely. There is a dedicated test for it.
- **The pixel to point conversion is correct**, uses the actual rendered raster size rather than a re-derived zoom (`:134-135`), clamps every box to the page rect (`:170-180`), and stays correct on rotated pages because `page.rect` and `get_pixmap` agree.
- **Real dependency injection at the right seam.** `image_to_data` is constructor-injected (`:29,35`) so the whole geometry path is testable without the binary — that seam is what made this entire audit possible without Tesseract. `TesseractOCRService` depends on `Settings` and a callable, never on a singleton; it satisfies the `OCRService` Protocol structurally with no inheritance.
- **The OCR to bbox contract is exact.** `OCRWord.start/end` are offsets into the very `page.text` string that `_build_page` assembles, and `bbox_service._words_for_span` (`bbox_service.py:101-105`) uses them directly. `normalize_name` is applied **only** inside `_similarity`/`_find_fuzzy_words` for comparison, never to the string that offsets index into — so the length-changing NFKD pass **cannot** corrupt index alignment. I looked for this specific class of bug and it is not there. `domain.py:67` even asserts `word.end <= len(page.text)`.
- **Resource handling is clean:** `with document:` (`:47`), `with Image.frombytes(...)` (`:84-88`), zero fd delta and zero temp-file residue measured across all sample PDFs, and pytesseract's own temp files are cleaned in a `finally`.
- **No bare `except:` and no silent swallowing** in either file. Every skip path except the confidence filter logs; every raise chains `from exc` and carries the page number.
- **Meaningful, structured, non-PII logging** with durations at both document and page level (`:55-60, 68-73, 113-119`) — pages, DPI, language, word counts, ms.
- **Degenerate PDFs are classified, not crashed:** empty, corrupt, encrypted and zero-page inputs all become typed `OCRProcessingError`s with distinct messages, and `errors.py`'s hierarchy lets `extract.py` map dependency failures to 503 and pipeline failures to 500.
- **Configuration is centralized and bounded** — DPI, language, timeout and confidence all come from `Settings` with validated ranges and are all present in `.env_example`.
- **`text_normalization` nails the graded accent trap** (`María González` == `Maria Gonzalez`), is 19 lines, has one job, and is shared by the bbox and fuzzy layers rather than duplicated.
