# CR-002 — No rerank-score gate: the LLM decides "not found"

- **Type**: B (implementation learning)
- **Origin**: live smoke test before the PR (2026-10-21)
- **Description**: with the gate at −2.59, `/api/ask` answered "not found" to "Who is
  the CEO of the company?" (memo top score −3.00) and "Who wrote the memo?" (−6.47),
  although the memo states "From: Margaret Thompson, CEO". The second question scores
  **below** an unanswerable one (q12, −4.49), so no threshold separates answerable from
  unanswerable on this reranker's scale: a gate calibrated on 13 questions just encoded
  those 13. With the gate removed, the top-5 passages always reach the LLM, whose prompt
  already says to reply the fixed not-found sentence when they don't contain the answer;
  an uncited reply still becomes "not found" and `sources` are still built by code.
  `eval_answers.py` with the two new questions: pass^3 **15/15**, 0 ungrounded sources
  (unanswerable and injection probes still answer "not found").
- **Affected sources**: ADR-014 (step 4 removed), TRD §2 Ask flow, §8 levers, §11,
  ADR-006 wording; DESIGN.md / DECISIONS.md.
- **Affected tickets**: T-005 (gate criteria superseded), T-006 (not-found path is the
  LLM's reply or an empty store)
- **Action**: source edit + code change (TDD) — `RERANK_MIN_SCORE` setting removed;
  golden q14/q15 added as regressions.
- **Cost accepted**: every question with at least one stored chunk costs one LLM call.
- **State**: applied
