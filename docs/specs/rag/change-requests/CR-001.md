- **Type**: B (implementation learning)
- **Origin**: preliminary run of spike S6 during planning (2026-10-21), dev box CPU
- **Description**: `BAAI/bge-reranker-v2-m3` takes 21.1 s to score 20 (question,

  swapping the reranker model for speed (the reranker step stays mandatory).
- **Affected sources**: TRD §8.2 (reranker rows), §15 S6 (result); ADR-014 (amended
  model choice + measurement table)
- **Affected tickets**: T-004

- **Result**: ADR-014 and TRD updated; T-004 v1 → v2 (default model, logit scale, spike
  re-measures the configured model). T-005 unchanged (its gate is calibrated on whatever
  scale the configured reranker produces). T-004 back to pending-approval.
