# Requirements traceability — README requirement → rule → verification

Every graded requirement in README §"Requirements that matter" maps to a rule and a
mechanical check. Keep this table current; a requirement without a check is a gap.

| README requirement | Rule | Verified by |
|---|---|---|
| SOLID, separation of concerns | CONSTITUTION §1, §6 | `lint-imports` (layers + framework-free contracts in `pyproject.toml`); review |
| Services depend on abstractions (Protocols/ABCs), not singletons | CONSTITUTION §1.3, §4, §5 | `app/application/ports.py`; `tests/unit/application/test_extract_names.py` runs `ExtractNames` on `tests/fakes/` |
| Dependency injection | CONSTITUTION §4.5, ADR-012 | `build_container` in `app/main.py` is the only adapter construction; API tests inject fakes via `create_app(build_container=...)` (`tests/unit/api/conftest.py`); `lint-imports` |
| Thin routers; logic testable without HTTP | CONSTITUTION §2.1 | `tests/unit/application/test_extract_names.py` (no `TestClient`); `app/api/extract.py` = validate → use case → map |
| Config: no hardcoded hosts/ports/models/thresholds/DPI | CONSTITUTION §6 (Configuration), §12 | `tests/unit/infrastructure/test_settings.py`; `.env.example` lists every `Settings` key; T-007 tests change limits via `Settings` |
| Timeouts + retries on external calls (LLM, vector store) | CONSTITUTION §8, ADR-010 | LLM: SDK `timeout`/`max_retries` from `Settings` (`DOCINTEL_LLM_TIMEOUT_SECONDS`, `DOCINTEL_LLM_MAX_RETRIES`); `tests/unit/infrastructure/test_openai_answer_generator.py` (fake server: timeout → `llm_timeout`, 429 → `llm_rate_limited`, 5xx/401 → `llm_unavailable`). Vector store: embedded Chroma is in-process (no network call to time out or retry); its errors → `vector_store_unavailable` (`tests/integration/test_chroma_vector_store.py`). Docker keeps it embedded (owner decision, TRD §8): its files persist on the `vector-store` volume; a networked store would add timeout/retry in its adapter |
| Meaningful failure modes; no `except: pass` | CONSTITUTION §8, §12 | ruff (`S110`, `BLE001`, `E722`); `tests/unit/api/test_errors.py`, `test_extract_route.py`, `test_upload_validation.py`, `test_ingest_route.py`, `test_ask_route.py` (every code → status) |
| Reject non-PDF by content, empty, oversized; validate bodies | CONSTITUTION §8 (Validate at the edge) | `tests/unit/api/test_upload_validation.py` (text as `.pdf` → 415, PDF as `.txt` → 200, empty, oversize, encrypted, broken, page limit, bad `names`) |
| No leaked file handles / temp files | CONSTITUTION §8 (Resources are scoped) | `test_upload_validation.py::test_no_temp_files_are_left_behind` (accepted + spooled oversize); `tests/integration/test_tesseract_ocr.py::test_no_temp_files_are_left_behind`; Chroma files released at shutdown: `tests/integration/test_chroma_vector_store.py::test_closing_releases_the_files_so_the_folder_can_be_deleted`, `tests/unit/api/test_lifespan.py` |
| Structured logging with context | CONSTITUTION §9 | `tests/unit/infrastructure/test_logging.py`, `tests/unit/api/test_request_id.py`; no-PII checks in `test_extract_names.py`, `test_alignment.py`, `test_ingest_document.py`, `test_retrieve_chunks.py`, `test_answer_question.py`, `test_ask_route.py`; API key never logged: `tests/unit/test_composition_root.py` |
| OCR every page incl. first | TRD §1, §2 (Extract flow) | `tests/unit/application/test_ocr_all_pages.py`; `tests/integration/test_tesseract_ocr.py`; `tests/e2e/test_extract_samples.py` (both pages of 2-page samples) |
| Boxes in PDF space, not pixels | TRD ADR-003 | `tests/unit/domain/test_geometry.py` (px→pt); DPI-independence in `test_tesseract_ocr.py`; e2e boxes within 612×792; `scripts/eval_boxes.py` (100 % re-OCR) |
| Case/accent-insensitive, OCR-noise-robust, full-string matching | TRD ADR-005 | `tests/unit/domain/test_name_matching.py` on `tests/golden/name_pairs.json` (19 pairs, 0.90 and 0.80) |
| Chunking never cuts words | TRD ADR-011, ADR-015 | `tests/unit/domain/test_chunking.py` (200-seed property tests: no word lost, duplicated or cut; budget respected; oversized paragraphs split only between sentences); `tests/e2e/test_ingest_samples.py` (real chunks within the token budget) |
| Grounded answers; no hallucinated `sources` | TRD ADR-006, ADR-014 | `tests/unit/domain/test_grounding.py` (sources only from cited passages that were sent; uncited → not found); `tests/unit/application/test_answer_question.py` (no LLM call without evidence); `tests/e2e/test_ask_samples.py`; `scripts/eval_retrieval.py` (hit@k, gate calibration); `scripts/eval_answers.py` (pass^3 + 100 % grounding) |
| Vector IDs unique across documents | TRD ADR-007 | `tests/e2e/test_ingest_samples.py::test_a_second_document_does_not_overwrite_the_first` and `::test_reingesting_the_same_pdf_keeps_exactly_one_copy`; `tests/unit/application/test_ingest_document.py` |
| Tests: tricky logic (mock heavy models) + ≥1 e2e | CONSTITUTION §7 | `pytest -m "not integration"` (fakes = the "mocks" the README asks for); `tests/e2e/test_extract_samples.py`, `test_ingest_samples.py`, `test_ask_samples.py`; evals `scripts/eval_ner.py`, `eval_boxes.py`, `eval_retrieval.py`, `eval_answers.py`, `time_reranker.py` |
| Disclose AI use; own every line | README §Use of AI tools | `DECISIONS.md` section |
| Containerization (bonus) | TRD §8, ADR-008 | `Dockerfile` (Tesseract, baked models, non-root `uid 10001`), `docker-compose.yml` (read-only FS, healthcheck on `/health`, `vector-store` volume); verified: `docker compose up` → healthy, extract/ingest/ask OK, data survives a restart |
| Audit viewer (bonus) | TRD §3 | `app/api/viewer.html` served at `/viewer`; `tests/unit/api/test_viewer.py` |
